Context

The challenge

Email attachments can arrive throughout the day and may need to be downloaded and sorted by hand. Without clear rules, important files can be difficult to find in a busy inbox or Drive.

Approach

The solution

The workflow checks incoming email and applies rules based on sender, file type, or subject. It saves each attachment to the matching Google Drive folder so documents are easier to locate.

Process

How it works

1

Receive an email

The workflow checks for an incoming message that includes an attachment.

2

Check the sorting rules

It checks details such as the sender, attachment type, and email subject.

3

Choose the Drive folder

The matching rule determines which Google Drive folder should receive the file.

4

Save the attachment

The attachment is saved in the selected folder, where it can be found later without sorting it manually.

Outcome

Attachments are sorted into the right Drive folders

This demo shows how email attachments can be organized automatically using rules for sender, file type, or subject. Files are saved to the corresponding Google Drive folders, making them easier to find.
